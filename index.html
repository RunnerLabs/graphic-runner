Windows 10/11

Runtime included
  1. Download GraphicRunnerInstallBeta.exe.
  2. Verify its SHA-256 checksum:79DEF8B878C8DF3B6FDA8C77773C4DFA4311B3818A88A81B3EF6245A4349F7C1
  3. Run the installer. Java is already included.
  4. This unsigned beta may display Windows protected your PC. After verifying the checksum, select More info, confirm the app name, then select Run anyway.
  5. Accept the beta license when Graphic Runner opens.

Do not disable Defender or SmartScreen. Trusted code signing is the permanent fix for the warning.

Linux x64

Native runtime included
  1. Download graphicrunner_0.0.17-1_amd64.deb and verify its checksum:1AECBF89E2EA73702A7178245CD41874539CEF062A47C10483665E16F1413AAB
  2. Install it with sudo apt install ./graphicrunner_0.0.17-1_amd64.deb.
  3. Launch GraphicRunner from your desktop application menu.
  4. For a no-install option, download the portable GraphicRunner-Linux-x64-0.0.17.tar.gz bundle.

Built and tested natively on an Ubuntu 22.04 baseline. Java is included. Wine and Bottles are no longer required.
