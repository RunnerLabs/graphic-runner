Build, edit, and export without sending your work to a server. Use Graphic Runner alone or beside the tools already in your workflow.

Layers + artboards

Group, mask, reorder, and organize separate designs in one working file.

Local AI

Select, inpaint, upscale, and polish sketches on your machine. Your artwork stays local.

Export control

Your machine. Your mess. Your file.

Graphic Runner does not collect personal data, upload artwork, monitor activity, build profiles, train on user content, or use a remote AI service. AI-enhanced editing runs locally.

Open it. Make something.

Choose the native package for your machine. Each package includes Java and the local models used by Graphic Runner.

Windows 10/11

Setup
  1. Download GraphicRunner-0.0.23-Windows-Setup.exe.
  2. Verify the SHA-256 checksum.79E39475E0C8FB78A49BEAB6A52B58510111F512CE08117F7CCEC7CEAD509DE9
  3. Run Setup, then accept the beta license when Graphic Runner opens.

This unsigned beta may show a publisher notice. Verify the checksum, confirm the app name, and continue from More info. Do not disable Windows security.

Linux x64

Native
  1. Download graphicrunner_0.0.23-1_amd64.deb.
  2. Verify the SHA-256 checksum.AD901C06F4816F4A5AD97CCD33A5E4DD7DA90E92955A73CE689907664F190356
  3. Install with sudo apt install ./graphicrunner_0.0.23-1_amd64.deb.
  4. For a no-install option, use the portable Linux bundle.

Java is included. Vulkan and OpenMP are optional for native AI upscale. Wine and Bottles are not required.
