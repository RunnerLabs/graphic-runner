v0.0.22.3 Creative Control Update

Build a workspace around the way you create, gain tighter layer and animation control, and turn sketches or clean illustrations into editable vector work without sending artwork to a server.

  • UI ManagerDrag tool sections between tabs or reorder, hide, restore, and reset the whole dock from one compact view.

  • Sketch + Image TraceChoose centerlines, sharp geometry, fills, or clean PNG curves with local AI Auto Polish when wanted.

  • Precise pixel workZoom deeper, fill with Paint Bucket, use corrected Polygon Selection, and rely on selection-paint Undo.

AI-enhanced features and privacy

Installing, launching, or using Graphic Runner—including its AI-enhanced features—acknowledges the included license terms. AI-enhanced tools perform only their described editing functions. Graphic Runner does not collect personal data, upload artwork, monitor activity, build profiles, train on user content, or use a remote AI service. Processing stays on the user's device.

Windows 10/11

v0.0.22.3 installer
  1. Download and run GraphicRunner-0.0.22.3-Windows-Setup.exe.
  2. Verify its SHA-256 checksum:28D2F616BA4BBBF9D2F1EC6DC0594FDCBC927DB4FAC29976068B9916A05F25DD
  3. The installer includes Java, adds Graphic Runner to the Start menu, and registers a normal Windows uninstaller.
  4. This unsigned beta may display Windows protected your PC. After verifying the checksum, select More info, confirm the app name, then select Run anyway.
  5. Accept the beta license when Graphic Runner opens.

Do not disable Defender or SmartScreen. Trusted code signing is the permanent fix for the warning.
