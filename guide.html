Graphic Runner / Start here

Open it.
Make something.

Graphic Runner is an offline desktop studio for images, type, vectors, masks, motion, merchandise, and print work.

01 Start

Create an artboard or import an image. Each artboard keeps its own layers, crop, and workspace position.

02 Build

Use layers for images, text, vectors, paint, planes, and masks. Select a layer before applying DTF or layer-specific effects.

03 Shape

Use Photo Runner, Contour Flow, Signal Track, color grading, blur, and glow. Presets move the controls and remain editable.

04 Finish

Export still artwork, print files, or motion. PNG, JPG, TIFF, PDF, and SVG retain the requested print DPI metadata.

Windows / Install

Download. Verify. Open.

  • Download the current Windows installer.
  • Verify the SHA-256 checksum shown on the release page.
  • Open Setup. The unsigned beta may show a Windows publisher notice.
