# Graphic Runner v0.0.5 Public Beta

This is the first public Windows beta of Graphic Runner.

## Included

- Offline Windows desktop application with bundled Java runtime
- Unified Ember branding with the new GR application and installer icon
- Text, logo, and symbol input modes
- 25 graphic effects with adjustable controls
- PNG, GIF, and CMYK TIFF export workflows
- Color management and ICC soft-proof support
- Windows EXE and MSI installers

## Downloads

- `GraphicRunnerInstallBeta.exe` — recommended for most testers
- `GraphicRunnerInstallBeta.msi` — managed or advanced installation
- `SHA256SUMS.txt` — integrity checksums

## Beta notice

This software is a public beta. Save backup copies of important artwork and verify exported files before relying on them in production.

The installers are not yet digitally signed, so Windows may display an unknown-publisher or SmartScreen warning. Download only from the official `RunnerLabs/graphic-runner` repository and verify the published SHA-256 checksum.
